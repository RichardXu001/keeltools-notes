不花钱先配齐一套：免费额度的组合思路

2026-10-20 · 约 8 分钟

订阅疲劳是真的：把每个位置都买上旗舰，一个月轻松超过 $100。但大多数人的用法，免费档就能覆盖七成。

结论：按四个位置配——对话、搜索、笔记、自动化——每个位置先用免费档，两周后只为最疼的那个位置付费。这套组合的月成本是 $0，升级决定推迟到有证据之后。

01 先划四个位置

四个位置，各管一件事
位置管什么免费档常见候选
对话写、改、问、翻译ChatGPT / Claude / Gemini 免费档
搜索带引用的检索与摘要Perplexity / NotebookLM
笔记知识沉淀与连接Obsidian / Notion / Capacities
自动化定时任务与跨应用串联n8n 自托管 / Make 免费档 / Zapier 免费档

四个位置里，对话是唯一一个「免费档真的会撞墙」的位置——消息数、模型档位、文件额度都受限。其他三个位置的免费档，对轻中度使用基本无感。

02 组合示例：一个轻量个人组合

对话给 ChatGPT 或 Claude 免费档（二选一即可，同时用两个只会分散历史记录）；搜索给 Perplexity；笔记给 Obsidian——本地文件、零锁定，将来换工具数据带得走；自动化先用 n8n 自托管或 Make 免费档。

想看这套组合里每个工具的完整档案（定价、功能、优缺点），在主站 工具目录 按「免费」筛一遍，候选名单五分钟就能拉出来。

03 什么时候打破「只用免费档」

三个触发条件

一，两周内同一个「额度用完」的提示出现三次以上——撞的是真墙，不是心情。二，某个工具开始出现在你每天的第一件事里——高频工具的付费档才值。三，免费档的功能缺口挡住了工作流（比如需要 API 或团队共享）——这是能力问题，不是额度问题。

一个反例

为了「可能用得上」买全家桶，是订阅疲劳的主因。免费档组合的意义就是把「可能」变成证据：用出来的痛，才付钱。

04 升级路径参考

真到付费那天，多数人的第一笔钱花在对话位置（$20 档的个人订阅），第二笔花在自动化（自托管 n8n 其实还是免费，Make 的付费档按任务数计费）。搜索和笔记的位置，免费档大多够用很久。

如果只能记一条：$0 组合跑两周，用出来的痛才付钱。订阅是买证据之后的事。
